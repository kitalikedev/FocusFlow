### Mỗi sprint có 3 mục

| Mục | Viết gì |
| :--- | :--- |
| 1. Việc đã làm | Các việc có pull request của bạn đã được liệt kê sẵn. Bổ sung việc không có pull request: họp, tìm hiểu, review, thử nghiệm, hỗ trợ bạn khác |
| 2. Khó khăn và cách giải quyết | Vấn đề bạn gặp và cách bạn xử lý |
| 3. Tự đánh giá đóng góp | Mức 1 – 5 và 1 – 2 câu nhận xét |

### Cách làm

1. Tạo nhánh mới từ `main`, ví dụ `docs/self-report-<tên GitHub>`.
2. Mở file của bạn, thay các dòng _(viết ...)_ bằng nội dung thật của bạn, bằng lời của bạn. Xóa phần "Hướng dẫn" ở đầu file khi viết xong.
3. Sprint nào bạn không có pull request vẫn phải viết, ghi những việc khác bạn đã làm trong sprint đó.
4. Commit, ví dụ: `Add my self-report for the 5 sprints`. Mở pull request vào `main` và nhờ một bạn duyệt.

Chỉ sửa file của chính bạn. Giảng viên dùng self-report để chấm điểm cá nhân, nên hãy viết đúng sự thật.
