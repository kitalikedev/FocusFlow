### Trong mỗi file, mỗi sprint có 6 mục

| Mục | Viết gì |
| :--- | :--- |
| 1. Việc đã làm | Các pull request của bạn trong sprint đã được liệt kê sẵn. Bổ sung việc không có pull request: họp, tìm hiểu, review, thử nghiệm, hỗ trợ bạn khác |
| 2. Kết quả | Cái gì chạy được, có thể chèn ảnh hoặc link |
| 3. Khó khăn và cách giải quyết | Vấn đề gặp phải và cách xử lý |
| 4. Điều học được | Kiến thức, kỹ năng mới |
| 5. Tự đánh giá đóng góp | Mức 1 – 5 và 1 – 2 câu nhận xét |
| 6. Kế hoạch sprint sau | Việc dự định làm; sprint 5 đã ghi sẵn "Không" |

### Cách làm

1. Tạo nhánh mới từ `main`, ví dụ `docs/self-report-<tên GitHub>`.
2. Mở file của bạn, thay mọi dòng _(viết ...)_ bằng nội dung thật của bạn, bằng lời của bạn. Xóa phần "Hướng dẫn" ở đầu file khi viết xong.
3. Sprint nào bạn không có pull request vẫn phải viết, ghi những việc khác bạn đã làm trong sprint đó.
4. Commit, ví dụ: `Add my self-report for the 5 sprints`. Mở pull request vào `main` và nhờ một bạn duyệt.

Chỉ sửa file của chính bạn. Giảng viên dùng self-report để chấm điểm cá nhân, nên hãy viết đúng sự thật. Ảnh đi kèm để trong thư mục `self-reports/images/`, tên bắt đầu bằng mã số sinh viên, ví dụ `24090021-sprint-4-seed.jpg`.
